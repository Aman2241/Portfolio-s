# Aman Raj - Portfolio

A brutally accessible, pixel-perfect, and performant portfolio website built with React, Vite, and Tailwind CSS (v4).

**Live Demo:** [https://Aman2241.github.io/Portfolio-s/](https://Aman2241.github.io/Portfolio-s/)

![Portfolio Preview](/public/profile.jpg)

## 🚀 Features

- **Brutalist Design System**: High contrast, bold information hierarchy, and vibrant accents.
- **Sticky Sidebar**: Persistent navigation with personal branding and contact details.
- **Responsive Layout**: Adapts seamlessly from desktop to mobile.
- **Dynamic Content**:
  - **About Section**: Categorized technical skills (Backend, Cloud, DevOps, etc.).
  - **Experience**: Detailed work history timeline.
  - **Hero**: Animated marquee and bold typography.
- **Performance Focused**: Built on Vite with optimized assets.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Fonts**: 'Archivo Black' (Display) & 'Inter' (Body)

## 🏃‍♂️ Getting Started

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Run Development Server**
    ```bash
    npm run dev
    ```

3.  **Build for Production**
    ```bash
    npm run build
    ```

## 🎨 Customization

- **Profile Image**: Replace `public/profile.jpg`.
- **Colors**: Edit CSS variables in `src/index.css`.
- **Content**: Update components in `src/components/`.
